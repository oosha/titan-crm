Patterns

Patterns coordinate routes, page ownership and component composition. They describe how a task behaves across a whole screen; they do not add a new ds-* class.

Data visualization

The design-system catalog for charts. These components define reading order, colour, density and accessibility independently of the rendering library and are the source of truth for implementations in ECharts or another renderer.

Directions

A direction is one file that remaps semantic tokens. It may not add component rules or invent raw values — that constraint is what makes trying one cheap and abandoning one free.

Each column below is a live direction, side by side. The theme file is fetched and re-scoped to its column, so these are the real overrides rather than a copy of them — edit themes/soft.css, reload, and the difference moves. The Direction control in the header applies one to everything, including this tool.
